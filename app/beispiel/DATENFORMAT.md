# fabBoard – Datenformat / Data format

[Deutsch](#deutsch) · [English](#english)

Beispiele / Examples: `de/beispiel-cafe.json`, `de/beispiel-kurzfilm.json`, `en/example-cafe.json`, `en/example-shortfilm.json` (erzeugt mit / generated by `beispiele_erstellen.py`).

---

## Deutsch

### Ablage
Alle Daten liegen im **Datenordner** des Nutzers (Standard: `Dokumente\fabBoard`; der Ort steht in `%APPDATA%\fabBoard\ort.json`).

| Pfad im Datenordner | Inhalt |
|---|---|
| `projekte\<id>.json` | ein Projekt mit offenen Einträgen, offenen Archiv-Einträgen und Nachrichten |
| `projekte\<id>.archiv.json` | erledigtes Archiv des Projekts: `{ "id": "<id>.archiv", "archiv": [ … ] }` |
| `einstellungen.json` | `name`, `projekteOrdner`, `anbieter` und `modell` (Standard-KI), `kis` (alle eingerichteten KIs, `[{ anbieter, modell }]`), `sprache` (`de`, `en` oder leer = Systemsprache), optional `claude` (Pfad zu Claude Code) |
| `bilder\<projekt-id>\<datei>.png` | Screenshots zu Nachrichten |
| `_backup\` | automatische Sicherungen (je Datei die letzten 30) |
| `laeufe\` | Protokolle der KI-Läufe (`<id>.log`, `<id>.fehler.log`: letzter Lauf), Verlauf `<id>.verlauf.json` (`[{ start, ende, exit, ki, abgebrochen, grund }]`, neueste zuerst, höchstens 50) und die Regel-Kopie `ki-auftrag.md` |
| `beispiele\` | Projektordner des Übungsprojekts „Erste Schritte“ (in der Vorlage `"ordner": "{beispielordner}"`) |

Alle Dateien sind UTF-8 ohne BOM. Datumsangaben: `YYYY-MM-DD`, Zeitangaben `YYYY-MM-DD HH:MM`.

### Projekt (`projekte\<id>.json`)
| Feld | Bedeutung |
|---|---|
| `id` | Kurzname, Kleinbuchstaben, Ziffern und Bindestrich; gleich dem Dateinamen |
| `name`, `art`, `beschreibung` | Anzeige im Board |
| `ordner` | Projektordner auf dem Rechner; dort arbeitet die KI. Leer = KI-Start nicht möglich |
| `ki` | optional: KI für dieses Projekt (ein `anbieter` aus `kis` in `einstellungen.json`). Leer oder nicht eingerichtet = Standard-KI |
| `reihenfolge` | Position der Tabs (kleiner = weiter links) |
| `erstellt`, `geaendert` | Datum bzw. Zeitpunkt der letzten Änderung |
| `themen` | Liste `{ id, titel, items: [Einträge] }`. Das Thema mit `id: "spaeter"` überspringt die KI |
| `archiv` | Einträge, die entschieden sind und noch umgesetzt werden müssen (`umgesetzt: false`); Erledigtes verschiebt das Board nach `<id>.archiv.json` |
| `nachrichten` | Nachrichten an die KI |

### Eintrag (in `themen[].items`)
| Feld | Bedeutung |
|---|---|
| `id` | eindeutig, z. B. `i` + Zeitstempel |
| `typ` | `frage`, `frage-an-claude` (Frage an die KI, unabhängig vom Anbieter), `anweisung`, `idee`, `aufgabe`, `info` |
| `titel`, `text` | Überschrift und Erläuterung |
| `optionen` | Liste `{ t, empf, gewaehlt }`: Text, Empfehlung (genau eine pro Frage), vom Nutzer gewählt |
| `mehrfach` | `true` = mehrere Optionen wählbar |
| `kommentar` | Kommentar des Nutzers |
| `von`, `wer` | wer den Eintrag angelegt hat bzw. wer dran ist: `fabian` = der Nutzer, `claude` = die KI (Namen aus der ersten Fassung; gelten für jeden Nutzer und jede KI) |
| `quelle`, `erstellt` | Herkunft (z. B. „Nachricht 2026-11-05“) und Datum |
| `herkunft` | nur in „Später“: `{ id, titel }` des Themas, in das der Eintrag zurückgeht |

### Archiv-Eintrag
Ein Eintrag mit zusätzlich `themaId`, `themaTitel`, `antwort` (gewählte Optionen), `erledigtAm`, `umgesetzt` (`false` = wartet auf die KI) und nach der Umsetzung `ergebnis` (1–2 Sätze, was geändert wurde).

### Nachricht
`{ id, text, erstellt, von, status: "offen" | "erledigt", antwort, bild }`. `bild` ist optional: Pfad wie `daten/bilder/<projekt-id>/<datei>.png`, wobei `daten/` für den Datenordner steht.

## English

### Storage
All data lives in the user's **data folder** (default: `Documents\fabBoard`; its location is stored in `%APPDATA%\fabBoard\ort.json`). Field names are German; they are the same in every language.

| Path in the data folder | Content |
|---|---|
| `projekte\<id>.json` | one project with open items, open archive items and messages |
| `projekte\<id>.archiv.json` | completed archive of the project: `{ "id": "<id>.archiv", "archiv": [ … ] }` |
| `einstellungen.json` (settings) | `name`, `projekteOrdner` (projects folder), `anbieter` and `modell` (default AI provider and model), `kis` (all AIs set up, `[{ anbieter, modell }]`), `sprache` (language: `de`, `en` or empty = system language), optional `claude` (path to Claude Code) |
| `bilder\<project-id>\<file>.png` | screenshots attached to messages |
| `_backup\` | automatic backups (last 30 per file) |
| `laeufe\` | logs of AI runs (`<id>.log`, `<id>.fehler.log`: last run), history `<id>.verlauf.json` (`[{ start, ende, exit, ki, abgebrochen, grund }]`, newest first, at most 50) and the rules copy `ki-auftrag.md` |
| `beispiele\` | project folder of the practice project “First steps” (in the template `"ordner": "{beispielordner}"`) |

All files are UTF-8 without BOM. Dates: `YYYY-MM-DD`, timestamps `YYYY-MM-DD HH:MM`.

### Project (`projekte\<id>.json`)
| Field | Meaning |
|---|---|
| `id` | short name: lower-case letters, digits and hyphens; same as the file name |
| `name`, `art` (type), `beschreibung` (description) | shown in the board |
| `ordner` | project folder on the computer; the AI works there. Empty = the AI cannot be started |
| `ki` | optional: AI for this project (an `anbieter` from `kis` in `einstellungen.json`). Empty or not set up = default AI |
| `reihenfolge` | tab order (smaller = further left) |
| `erstellt`, `geaendert` | created date and last change |
| `themen` (topics) | list `{ id, titel, items: [items] }`. The AI skips the topic with `id: "spaeter"` (later) |
| `archiv` (archive) | items that are decided but not yet implemented (`umgesetzt: false`); the board moves completed ones to `<id>.archiv.json` |
| `nachrichten` (messages) | messages to the AI |

### Item (in `themen[].items`)
| Field | Meaning |
|---|---|
| `id` | unique, e.g. `i` + timestamp |
| `typ` (type) | `frage` (question), `frage-an-claude` (question for the AI, whatever the provider), `anweisung` (instruction), `idee` (idea), `aufgabe` (task), `info` |
| `titel`, `text` | title and explanation |
| `optionen` (options) | list `{ t, empf, gewaehlt }`: text, recommended (exactly one per question), chosen by the user |
| `mehrfach` | `true` = multiple choice |
| `kommentar` | the user's comment |
| `von`, `wer` | who created the item / whose turn it is: `fabian` = the user, `claude` = the AI (names from the first version; they apply to every user and every AI) |
| `quelle`, `erstellt` | source (e.g. "Message 2026-11-05") and date |
| `herkunft` | only in "Later": `{ id, titel }` of the topic the item goes back to |

### Archive item
An item plus `themaId`, `themaTitel`, `antwort` (chosen options), `erledigtAm` (date done), `umgesetzt` (`false` = waiting for the AI) and, once implemented, `ergebnis` (one or two sentences on what was changed).

### Message
`{ id, text, erstellt, von, status: "offen" | "erledigt" (open | done), antwort (reply), bild (image) }`. `bild` is optional: a path like `daten/bilder/<project-id>/<file>.png`, where `daten/` stands for the data folder.
